Slay The Spire Characters

Ironclad

"The remaining soldier of the Ironclads. Sold his soul to harness demonic energies."
The Ironclad wields powerful strikes, formidable defense, and draws fiendish strength from demonic benefactors. He starts with 80 HP and can manipulate the Exhaust mechanic.

Silent

"A deadly huntress from the foglands. Eradicates foes with daggers and poisons."
The Silent weakens foes with poison and cheap tricks while staying one step ahead through draw and discard synergies. She starts with 70 HP.

Defect

"Combat automaton which became self-aware. Ancient technology allows manipulation of Orbs."
The Defect channels elemental Orbs into slots that trigger passive effects each turn or can be Evoked for burst damage. Starts with 75 HP.

Watcher

"A blind ascetic who has come to 'Evaluate' the Spire. Master of the divine Stances."
The Watcher shifts between Calm, Wrath, and Divinity stances to multiply damage and generate energy. She starts with 72 HP and excels at deck control via Scry.

Font Sizes — Absolute & Relative Units

  • The Spire awaits. 10px (absolute) Use px for fine UI details like borders or icon labels where pixel-perfect control is needed, e.g. a caption under a thumbnail.
  • The Spire awaits. 12pt (absolute) Points are a print unit (1pt = 1/72 inch). Use pt inside @media print stylesheets, e.g. setting body to 12pt for a printable document.
  • The Spire awaits. 1rem (relative to root) rem scales with the root font-size. Use for body text so the whole page scales consistently when a user changes their browser default font size.
  • The Spire awaits. 1.5em (relative to parent) em multiplies the parent element's font-size. Use for icons or labels that should always be proportional to the surrounding text.
  • The Spire awaits. 4vw (relative to viewport) vw scales with viewport width. Use for hero headings that should fill the screen proportionally on any device without overflowing.
  • The Spire awaits. 150% (relative to parent) % works like em for font-size. Use inside a component to bump a sub-heading up 50% from whatever the container's base size is.

CSS Positioning — 4 Types

The arena below uses position: relative as a containing block. The footer at the bottom of the screen uses position: fixed.

position: static — Default flow. No offset properties.
position: relative — top:10px left:30px from its own normal position.
position: absolute — bottom:16px right:16px of nearest positioned ancestor.

static

The default. Elements stack in document flow. Offset properties (top/left etc.) have no effect. Use it to reset a positioned element back to normal flow.

relative

Stays in document flow but can be nudged with offsets. Also creates a new containing block for absolute children. Use for slight visual tweaks or as a wrapper.

absolute

Removed from flow; positioned relative to the nearest positioned ancestor. Use for tooltips, badges, dropdown menus, or decorative overlays inside a container.

fixed (used by footer)

Removed from flow; positioned relative to the viewport and stays put while the page scrolls. Use for persistent navbars, cookie banners, or a sticky footer.
